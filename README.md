# Go 服务入口网关

当前版本先实现版本化路由、本地 HTTP 上游转发、整份配置热更新、上游状态和请求记录。

## 运行

```bash
go run ./cmd/gateway -config configs/gateway.json
```

示例：

- `GET /v1/demo/...` 转发到 `demo-v1` 上游。
- `GET /v2/demo/...` 转发到 `demo-v2` 上游。

## 配置语义

- 配置通过管理接口整份校验、整份替换；非法配置保持旧快照不变。
- 请求进入时获取不可变路由快照，在途请求不会被后续配置替换或回退影响。
- 只有路由显式允许、请求方法匹配且尚未收到上游响应的连接级失败才会重试。
- 一旦上游响应头返回，网关只向客户端复制这一份响应体；取消会同时结束上游请求，不会拼接另一份响应。
- 上游状态与请求记录分别维护，互不影响路由快照。

## 管理接口

- `GET /__gateway__`：查看当前配置。
- `PUT /__gateway__/config`：提交完整 JSON 配置并原子替换。
- `GET /__gateway__/status`：查看上游请求计数与连续失败数。
- `GET /__gateway__/records`：查看最近请求记录。

## 验证

```bash
go test ./...
go test -race ./...
```

集成测试覆盖版本化路径、允许与禁止重试、长响应无重复、客户端取消和配置回退期间的在途请求。
